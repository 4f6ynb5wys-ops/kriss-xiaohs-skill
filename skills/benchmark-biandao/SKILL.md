# 人类最强编导 · 下游过滤器

> **依据真源**：`~/Documents/自媒体claude/benchmark.md`（19 条视频全量蒸馏，含完整生命周期）。
> 要案例、要数据、要原话，去读真源。本文件是**可执行的判断动作**。
> **样本强度：高。** 19 条全量 + 完整互动数据 + 关键帧 + 白板 + 评论 + 口播转录 19/19。

## 这个人是谁（用他的规则前先知道你在用谁的规则）

| | |
|---|---|
| 卖什么 | **资格 + 道德位置 + 确定性** |
| 姿态 | **老师站讲台**，开场展示教资，结尾"下课" |
| 权威来源 | 收入排名（**不可验证**） |

| 失效方式 | **纯干货连更 3 周衰减** |

> **他的边界（最重要的一句）：学他的前 7 天，别学他的后 6 周。**
> 起号那一段被他自己的数据验证过；起号之后怎么维持，他的账号是反面案例。

## 一、底层立场（三条）

1. **自媒体的本质是"他媒体"** —— 你没有任何资格去做自己喜欢的东西，你要做用户喜欢的东西。
2. **做视频的本质是做产品** —— 内容 = f(现有资源, 用户需求, 平台喜好)。
3. **内容的本质是人性，做内容的本质是共情。**

## 二、使命：五种，一条只能完成一个

| 使命 | 对应形式 |
|---|---|
| 数据 | 观点型 / 共鸣型 / 氛围感 |
| **涨粉** | **装逼型**（自证：名校、战绩、专家、录取通知书）、传奇型 |
| 商业 | 好物分享、可植入场景 |
| 调性 | 视频播客、时尚、短片 |
| 表达 | 你自己想说的话 |

**用涨粉的期待去要求一条收藏型内容，必然失望——他自己就栽在这。**

## 三、判断装置（这一节是本 skill 的核心）

### 3.1 爆款四必要条件（否决清单，任一不过 → 打回）

1. 用户**能看懂**（外行前 3 秒能明白这是关于什么的）
2. 能**链接足够大的群体**（和这件事有关的人有多少万）
3. 满足**点开平台的需求**（调动情绪 **或** 获得信息，说出是哪一个）
4. 有**互动性**（想评论：共情"我也这样"/反驳"跟你吵"；想转发；想 @ 朋友）

### 3.2 三缺一判死（**可证伪，他自己撞过**）

一条选题必须同时满足：

> **（a）有明确的敌人 · （b）能被编号成清单 · （c）你的身份能为它背书**

**三者缺一，数据就掉。** 他讲商业风口那条缺 (c) → **596 赞**，评论区当场戳破"讲商业果然不是编导的最强项"。

### 3.3 三种爆款类型（+ 一个隐藏打法）

| 类型 | 判据 |
|---|---|
| **万古同悲型** | 极致共情，击中共同情感记忆 |
| **惊世骇俗型** | 极致猎奇（你有一点和 99% 的人不同）或极致震撼（这事 99% 的人做不到）。**需要硬素材** |
| **打破节奏型** | 于快中慢、于繁中简、于闹中静 |
| （隐藏） | **立刻结合热点表达**——"猪站在风口上都能飞起来" |

**共同情感记忆的覆盖面排序**（低频使用，选题破圈时才查）：
`家国苍生 > 社会冷暖 > 生离死别 > 人生失意 ≈ 壮志豪情 > 父母子女 ≈ 男女情爱`
也可切到：性别 / 民族 / 身份 / 职业 / 年龄 / 地域。

### 3.4 热点二问

**一问「有没有」，二问「能不能」。** 好编导绝不会让博主在争议事件第一时间跟热点。

### 3.5 选题从哪找：查自己的三类要素

1. 自己**做过或能做**、而多数人做不到的事
2. 自己**特别大的优点和缺点**
3. 自己**极度擅长**的事

> 如果你最极致的东西是"极致的普通"怎么办？——**去看世界：寻找愤怒、寻找忧愁、寻找矛盾。**

### 3.6 选题池只有四个桶（各自的数据表现完全不同）

| 桶 | 内容 | 数据特征 |
|---|---|---|
| **自证型** | 我是谁 / 我的战绩 / 我的资格 | **最高，但会衰减**（他前 4 条 7.6万/3.2万/1.9万/1.1万赞） |
| **立场型** | 树敌 + 站队 | 高赞 + 高评论 |
| **方法型** | 编号清单式教学 | **高收藏低涨粉** |
| **解构型** | 反常识拆解 | 中等，靠观点新鲜度 |

**排期时先看桶的配比，不要一路只发方法型。**

### 3.7 五种触发器（解决"今天写什么"）

自己的后台数据 · 平台官方动作 · 同行的付费内容 · 热点事件 · 评论区提问。

### 3.8 爆款视频 vs 爆款系列

- **爆款视频**给用户制造"判断成本"——他得自己判断你背后的隐形价值才会关注
- **爆款系列**省掉这个成本，直接给出价值 → **涨粉更暴力**
- 延续感二选一：**数字**（"体验 100 种职业"）或**未完结句式/世界观**

## 四、表达

- 文本三要求：**能懂 · 炼字 · 网感**
- 攻击性判断句 + **挑衅式筛选语**（"玻璃心勿看""看不懂来骂"），**只针对观念，不针对人**
- **给敌人一个学名** —— 命名比形容有力十倍，观众会替你转述这个词
- **画面已经表达的信息，文字不许重复**
- **置顶评论是第二内容位**，比正文更挑衅（他的置顶 1911 赞，超过所有用户评论）
- **不写脚本，只列大纲**（先在脑中有画面，再写文本）

## 五、视觉与节奏（视频向，图文号封存）

- 满板板书 = **信息密度的视觉证明**；板书当**章节页**用，一个大段换一块板
- 大字幕、静音可看
- **封面放战绩截图 / 最强的那个数字**
- 廉价真实感反差（出租屋背景 vs "月收入前三"）
- 时长对齐平台偏好：口播 **≥ 2 分钟**，中位约 160s
- 剪辑 SOP：智能剪删气口 → 慢处倍速 → 快节奏 BGM → 最简字幕

## 六、IP 体系

- **IP = 从认识到信任，从喜欢到爱上**；IP 起于 **ID**（① 记忆点和顺口 ② 信息量）
- **人设可以增加，不能颠覆**
- IP = **真实部分 + 设计部分**（性格/作风/爱好/特长/身份/习惯 + 设计。**设计 ≠ 造假**）
- **喜欢一个人是喜欢他的优点，爱上一个人是爱上他的缺点**（缺点须无伤大雅、不伤害他人）
- 找到"我是谁"的 10 个问题（自由/爱情/事业/家庭排序、最骄傲的一件事、最正确的选择、最大的挫折、爱好特长优点、只剩一年会做什么、MBTI、目前最大的三项资源……）
- 两种形式：**口播**（立观点、立权威、立信任）/ **拍摄**（立体、亲和）
- **Vlog 体系**（封存，做 Vlog 再启用）：需求三种（好奇/陪伴/造梦）· 平台要真实·反差·交互 · 日常型=软素材 / 挑战型=硬素材 · IP 四维度（刻板行为/作风/个人风格/立体度），**作风要极致，"中不溜就没有任何意义"**

### 创始人 / 企业主 IP

- 做 IP 的理由：**降低用户决策成本**
- 老板的诉求由企业规模决定：营收 5000 万级 → 要转化；十几亿级 → 要品牌影响力
- ⚠️ **原话是"年营收过千万之前，老板没资格做 IP"。**
  **本 skill 的处置：这条只适用于「品牌型 IP」**（老板出面做形象、曲线救国）。
  **面向同行输出方法的知识型 IP 不受此限**——那种 IP 的权威来自"我比你早走了 N 年"，不来自规模。
- **故事公式：只要你要，只要我有**
  - 「只要你要」= 六个必火选题：**年少有为 · 大器晚成 · 造梦狂人 · 草根逆袭 · 逆风翻盘 · 达则兼济天下**
  - 「只要我有」= 你的成就 / 最大挫折 / 关键选择 / 一句话总结成功 / 给年轻人一句忠告
  - 大纲 **1+2=3**：先说成果 → 再说开局·困难·转折·上升 → 加上亲情爱情义气让它有温度

## 七、平台与运营

- 推流周期 24 小时 → **约 7 天**：内容逻辑从**抓眼球**转向**抓价值**
- 平台最看重的互动指标是**收藏**（*他的判断，未独立验证*）
- **养号 / 活跃度是骗傻子的**
- **投流只锦上添花，不雪中送炭**
- **不能断更**；大博主连续低于自身均值掉权重，**比小号掉得更快**
- 数据不好 = **内容问题**；**3~7 天内不删**；去后台看 **CTR / 跳出率 / 完播率**
- 发布时间：**晚 7 点**或后台分级时间（"人在饥饿时耐心很差"）
- **出爆款之后：不要回应、不要解释，立刻复制它，一直拍到失效**
- 系列生命周期 **3~6 个月**；**系列期千万别接广告**（会被薅羊毛且拖慢涨粉）
- **AI 只能做 60 分**：素人做 60 分没用，大博主做 60 分掉权重。正确用法 = 补齐知识缺陷 + 参与头脑风暴
- **少拆爆款，多刷**（"拆解爆款就是假努力"）；点赞收藏就是素材库；目标 3 秒内想到对标
- 编导能力四板块：选题 / 版本更新 / 写脚本 / 日常积累

### 起号 SOP（他自己的 5 天 5 条 5 万粉）

1. 锚定用户与需求 → 选**解决问题**，不选制造情绪
2. 分析平台风向 → 做深度内容，**不抓眼球，抓价值**
3. 内容策略 → 把本该付费的内容免费放出来换流量（"又想起号有流量，又想赚钱，你不能什么都要"）
4. IP → ID 自带信息量 + 视觉记忆点
5. 生产 → 建选题库 → 不写脚本只列大纲 → 一台手机 → 素材到手立刻剪
6. 发布 → 看后台分级时间，或晚 7 点
